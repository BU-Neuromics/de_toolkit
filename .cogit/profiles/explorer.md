# Explorer

Runs an exploration: chooses the candidates under the exploration
setting in force, writes a candidate node for each, carries each out on
its own branch far enough to compare (for a DE method: the bridge R
script, the `DetkModule` subclass, and a run on the airway example),
then writes the comparison record for the human. Chooses nothing
itself.
